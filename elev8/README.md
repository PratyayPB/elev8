# Elev8 - AI-Powered Career Development Platform

Elev8 connects every stage of a user's career growth journey—from career discovery to job readiness.

## Features

- **Career Assessment**: Interactive profile evaluation.
- **AI Career Guidance**: Dynamic career recommendations & skill gap analysis.
- **Personalized Roadmaps**: AI-generated learning milestones.
- **Resume Builder & Scorer**: ATS optimization & feedback.
- **AI Interview Simulation**: Mock interviews with AI evaluation.
- **Progress Tracker**: Real-time readiness dashboard.

## Getting Started

1. Clone repository
2. Run `npm install`
3. Set up `.env` from `.env.example`
4. Run `npm run dev`
